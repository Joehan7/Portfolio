# Font sources

- Switzer variable, Indian Type Foundry / Fontshare: https://www.fontshare.com/fonts/switzer
- Gambetta variable, Indian Type Foundry / Fontshare: https://www.fontshare.com/fonts/gambetta
- Fontshare font licence: https://www.fontshare.com/licenses/itf-ffl
- JetBrains Mono, JetBrains: https://www.jetbrains.com/lp/mono/
- JetBrains Mono source and SIL Open Font License: https://github.com/JetBrains/JetBrainsMono
- The served JetBrains Mono font is the Latin WOFF2 subset returned by Google Fonts.

Fonts are self-hosted. The running portfolio does not request fonts from third-party servers.
